How to insert new row into table?
to insert new row into table, we use insert into sql command.  there are 2 ways to insert new row. 

1st way 
syntax 
insert into <tablename> values ([value-1][value-2],[value-n])

Example 
insert into category values (0,'Mixture','mixture.jpg',1,0,CURRENT_TIMESTAMP)

insert into category values (0,'pen drives','pendrive.jpg',1,0,CURRENT_TIMESTAMP)

2nd way 
syntax 
insert into <tablename> (field-1,field-2,field-n) values ([value-1][value-2],[value-n])

example 
insert into category (title,photo) values ('sound bar','sound.jpg');
insert into category (title,photo) values ('microwave oven','microwave.jpg');

How to update existing row in table?
-------------------------------------
to update existing row in table, we use update sql command 
syntax 
update <tablename> set field=value, field-2=value-2, field-n = value-n [where <condition>]

Note, 
if we do not where clause in update sql statement, it will update all rows table 

example
-------------------------------
update all product set weight to 0 grams 
update products set weight=0

update price of all product by 1 rupees 
update products set price = price + 1

update product p001, set name to usb mouse, description to usb 3.0 mouse, price to 200 rs.
update products set name='usb mouse', description = 'usb 3.0 mouse', price = 200 where product_code='p001'

update product table, increase price by 50 of those product whose price is between 2000 to 3000 rupees. 
update products set price=price+50 where price>2000 and price<3000

update product set stock to 10 of those product whose id is below 10
update products set stock = 10 where id<10

update product set weight to 100 grams of those product which is manufactured in january month 
update products set weight = 100 where manufacture_date >= '2026-01-01' and manufacture_date<='2026-01-31'

Aggregate function
------------------------------
Function that works upon numeric field and returns single value is called Aggregate function.

sum(field)

avg(field)

min(field)
    min function return minimum value of given numeric field
max(field)
    max function return maximum value of given numeric field
count()

Joins
----------------------------------------------------------------------------------------------------
Join operation basically  makes join between any numbers of tables and display data as single virtual table.
to join multiple tables, there must be one common field between tables to be used in join.

what is common field?
common field is field in two table which has same data type and same set of values (domain values)

types of

INNER JOIN / Equi join
Inner join fetches only matching rows from all the tables using in join. here  matching rows means common field in both table has same value in both table

LEFT JOIN
Left join fetches all rows from left side table but only matching rows from right side table.  here  matching rows means common field in both table has same value in both table

RIGHT JOIN
right join fetches all rows from right side table but only matching rows from left side table.  here  matching rows means common field in both table has same value in both table

CROSS JOIN
FETCH DATA FROM BOTH TABLE WITHOUT ANY CONDITION

SELF JOIN
